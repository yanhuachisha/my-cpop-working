# 每日推荐功能需求分析

## 目标

当前阶段重点把“每日推荐一首华语歌”做好，所有艺人都使用统一的曲库、推荐与歌曲解读能力。

成功标准：

- 每天默认推荐稳定，同一天刷新不乱跳。
- 用户点击“换一首”时进入探索模式，可以换到不同歌曲。
- 推荐结果优先可试听；没有公开试听源时要明确降级。
- 推荐理由必须解释清楚：华语相关性、风格、情绪、年代、个人偏好、是否可试听。
- 不存储完整歌词，不存储音频文件，不使用非公开音乐平台接口。

## 数据资源

主数据：

- MusicBrainz：艺人、专辑、歌曲、作品关系，作为长期主 ID 底座。
- Wikidata：地区、语言、人物、别名、外部 ID 对齐。
- ListenBrainz：开放听歌趋势和后续用户授权听歌历史。
- Discogs：发行版本、厂牌和实体发行补充。
- 项目 seed 数据：用于 MVP 和人工校验华语识别。

试听资源：

- Deezer public preview API：只使用公开 30 秒 preview URL。
- preview URL 只作为临时播放链接，不下载、不缓存音频文件。
- 匹配时必须校验歌名，宁可无试听，也不播错歌。

## 推荐算法

默认推荐流程：

1. 从 `is_cpop=true` 的歌曲中取候选。
2. 为候选尽量解析 `preview_url`。
3. 按综合分排序。
4. 应用频率控制：demo 用户下周杰伦不每天出现。
5. 返回歌曲、艺人、专辑、相似歌曲、推荐理由、数据来源。

综合分权重：

- 个人偏好：30%
- 内容匹配：22%
- 可试听：18%
- 年代新鲜度：12%
- 华语相关性：10%
- 多样性：5%
- 探索随机性：3%

探索模式：

- `GET /api/daily-pick?user_id=demo&seed=xxx`
- seed 只影响探索分，不影响基础规则。
- 首页默认不传 seed，点击“换一首”才传 seed。
